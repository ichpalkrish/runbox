# Linux Execution Lab

An educational Linux command execution, tracing, isolation, and fault injection
project in C++20. Provisional CLI name: `runlab`.

Development is performed on an Arch Linux ARM VM (aarch64). Environment setup
is complete; application implementation has not started.
